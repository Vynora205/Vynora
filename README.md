# Vynora V1.5 — Full Upgrade

## Files
- `index.html` — complete V1.5 frontend with five generators, analyzer, A/B tester, history, local engine and AI provider abstraction.
- `api/generate.js` — secure serverless Gemini endpoint.

## GitHub Pages
The frontend works on GitHub Pages in Local Engine mode. GitHub Pages cannot execute `/api/generate`.

## Real AI
Deploy the same project to Vercel/Netlify (or adapt the function to your provider), then set the server environment variable `GEMINI_API_KEY`. Optional `GEMINI_MODEL` can select a supported Gemini model. Never place the key in `index.html`.

## V1.5 features
Content Pack, Edit, Music, Blog, Vlog, contextual local generation, secure AI backend, smart refinement actions, Analyzer, heuristic A/B Tester, local history, responsive UI, SEO metadata, accessibility/reduced-motion support, and premium bouncy motion.
